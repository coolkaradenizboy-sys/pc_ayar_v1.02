# PC Ayar v1.02 🚀

A lightweight Windows optimization and performance script inspired by FPS boost tools. Designed to tweak system settings cleanly and efficiently.

## Features ✨
- **Performance Toggles:** Optimize system resources for better gaming and responsiveness.
- **Standalone Executable:** Run directly via the compiled `.exe` without needing Python installed.
- **Administrator Privileges:** Automatically requests UAC admin rights for seamless execution.

## How to Use 📥
1. Go to the **Releases** section (or download directly from the repository).
2. Download `pcayar.exe`.
3. Right-click and choose **"Run as administrator"** to apply the tweaks.
